PX915 Traffic Flow Modelling documentation
==========================================

This documentation describes the traffic-flow simulation code developed for
the PX915 group project.

The project contains a one-dimensional TASEP model, a macroscopic PDE traffic
flow solver, and a multilane PDE extension with conservative lane-changing
source terms.
